# Portofolio Muhamad Arya Ramadhan

Website portofolio statis menggunakan HTML, CSS, dan JavaScript murni.

## Menjalankan secara lokal
Buka `index.html` di browser. Tidak membutuhkan instalasi atau proses build.

## Struktur
- `index.html` — struktur halaman
- `style.css` — tampilan dan responsivitas
- `script.js` — menu mobile dan interaksi navigasi
- `assets/` — foto profil dan karya

## Publikasi ke GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah seluruh isi folder ini (termasuk folder `assets`).
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu simpan.
6. Tunggu proses selesai; tautan website akan muncul di halaman Pages.

Catatan: Website menggunakan Google Fonts melalui koneksi internet. Jika font eksternal tidak tersedia, font sans-serif bawaan akan digunakan.
